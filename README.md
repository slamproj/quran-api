# Quran API (JSON statis)

Data Al-Qur'an dalam format JSON statis.

## Endpoint
- /index.json : daftar surah
- /surah/{n}.json : satu surah (Arab + terjemahan)
- /ayat/{n}/{a}.json : satu ayat

## Sumber
Teks Al-Qur'an dan terjemahan berasal dari Tanzil Project (https://tanzil.net).
Teks tidak diubah. Terjemahan Indonesia: (https://tanzil.net/trans/id.indonesian).
Lihat docs/meta.json untuk checksum file sumber.
